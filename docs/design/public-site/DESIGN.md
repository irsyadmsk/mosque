# Web unduhan MasjidKU — desain

Visual authority: pengguna memilih halaman aplikasi Irsyads, dikonfirmasi 2 Oktober 2026. Mengikuti palet dan pasangan font dari packages/design-tokens/src/tokens.css pada repo irsyads, logo MasjidKU dan Irsyads dari sumber first-party yang sama.

Navigasi: identitas produk di kiri, tautan Fitur/Cara pasang/Rilis dan tombol Ke irsyads.com di kanan. Breadcrumb menuju Beranda dan Aplikasi. Di ponsel navigasi berpindah ke baris kedua; tombol utama tetap tampak.

Permukaan mist, tinta navy, tombol mint dengan teks gelap. Heading Bricolage Grotesque, isi Manrope. Kartu fitur mengikuti etalase aplikasi. Ilustrasi papan diberi label data contoh. Konten dan URL APK beta tetap sama. Focus ring deep teal dan reduced motion dipertahankan.

Logo SVG: salinan dari packages/design-tokens/src/sublogo/masjidku_light.svg serta adaptasi sintaks dari Logo.astro; tidak mengubah geometri. Tidak menggunakan wallpaper/foto pengguna pada web publik.

Status: desktop dan ponsel 390px diperiksa lokal, tidak ada overflow; logo dan font dimuat; tautan utama dan APK benar; kontras teks utama/sekunder/tombol >=4.5:1. Publikasi disetujui pengguna pada 2 Oktober 2026.
