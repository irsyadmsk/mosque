            📐 Panduan & Preset Format URL Kamera IP / CCTV

            💡
            Wajib Diketahui untuk Kamera TP-Link Tapo (C200, C210, C310, TC70, dll):
            1. Buka aplikasi Tapo di HP → Masuk ke Pengaturan Kamera (Ikon Gerigi) → Pengaturan Lanjutan → Akun Kamera → Buat Username & Password akun kamera lokal.
            2. Format URL RTSP yang WAJIB dimasukkan (harus menyertakan username & password):
            • Sub-Stream (Sangat Direkomendasikan): rtsp://username:password@192.168.1.100:554/stream2 (Format H.264, instan terbuka, sangat ringan & bebas buffering di TV).
            • Main Stream (1080p/2K): rtsp://username:password@192.168.1.100:554/stream1.
            Catatan: Jika tanpa username & password, kamera Tapo otomatis menolak koneksi (Error 401).
